# ShopSphere

Enterprise E-Commerce REST API built with Laravel 13.

## Overview

ShopSphere is a scalable e-commerce backend
designed with clean architecture and SOLID principles.

## Tech Stack

- PHP 8.3+
- Laravel 13
- MySQL
- Redis
- Laravel Sanctum
- PHPUnit / Pest
- Docker

## Main Modules

- Authentication & Authorization
- Product Catalog
- Inventory Management
- Shopping Cart
- Orders & Checkout
- Payments
- Shipping
- Coupons & Discounts
- Reviews & Ratings
- Notifications
- Reports & Analytics

## Installation

1. Clone the repository.
2. Run composer install.
3. Copy .env.example to .env.
4. Configure your database.
5. Run php artisan key:generate.
6. Run php artisan migrate.
7. Run php artisan serve.
